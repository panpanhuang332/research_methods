# 18章圖解補充模組

本目錄新增研究方法18週學程的 **18章、36張SVG圖解**，沿用既有18章課綱與AI客服貫穿案例。每張圖包含讀圖重點、誤讀提醒、文字替代及適用的參考來源。數值、訪談片段和比較表中的文獻條目均為教學模擬，不是實際研究結果。

## 交付狀態與邊界

- `chapter-visuals.js`：獨立、可嵌入的唯讀 Web Component。
- `index.html`：桌面與手機的獨立預覽頁，可切換章節、展開全部、列印、放大及下載SVG。
- `tests/check_visuals.py`：瀏覽器檢查與离線教材封裝腳本；檢查結果以實際產出的 `qa-report.json` 為準。
- 本次開始檢查時，儲存庫僅有原 `README.md`，没有原教學網站完整程式碼。**本目錄尚未嵌入原網站各章，也不表示完整課程已移轉到GitHub。**
- 未改動原聯合入口、手機古今左右並列、古代站、登入／身分、學生作答、教師評閱、留言或資料庫。
- 模組不含登入選項、API呼叫、Cookie、瀏覽器儲存或外部字型。無字型檔隨包提供。

## 閱覽

直接用瀏覽器開啟 `visuals/index.html`。可使用 `#chapter-1` 至 `#chapter-18` 連到特定章。

瀏覽器檢查腳本會另外產生一份全部程式已內嵌的 `research_methods_18_chapter_visuals.html`，可單檔離線開啟，並匯出36張獨立SVG。

## 原網站的嵌入方式

取得完整原網站程式碼後，應先核對各章實際內文，再把圖解放到對應概念或案例附近，不移除既有文字，不改寫原路由、題庫、交卷或討論邏輯。

```html
<!-- 路徑請依原網站的部署基底設定；腳本整站載入一次即可。 -->
<script src="/visuals/chapter-visuals.js" defer></script>

<!-- 每章傳入該章編號。 -->
<research-chapter-visuals chapter="1"></research-chapter-visuals>
```

`chapter` 可為1–18；變更屬性會切換圖解。樣式封裝於Shadow DOM中，不污染原站樣式。若部署於GitHub Pages子目錄，使用符合該基底的相對路徑，而非直接假設根目錄。

## 方法與授權注意

- 概念圖的箭頭明確區分研究程序、待檢驗假設及因果假設，不把示意當成已確認結果。
- 第12章採已知母體標準差的常態教學模型；正式分析不可直接假設這些條件成立。20條示範區間為預先設定的示意樣本，18條涵蓋，不宣稱本次恰好95%。
- 第15章雙鑽石依 Design Council 概念重新繪製並中文化，標明改作與 CC BY 4.0。來源：https://www.designcouncil.org.uk/resources/the-double-diamond/
- 其他概念查核：Bhattacherjee (2012)，https://digitalcommons.usf.edu/oa_textbooks/3/；OpenIntro Statistics，https://www.openintro.org/book/os/；NIST信賴區間說明，https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm；Zotero官方指南，https://www.zotero.org/support/quick_start_guide。
- 倫理示意不是法律意見、倫理核准或免審認定；正式研究依所屬機構確認。

## 執行檢查

```sh
python -m pip install playwright
python -m playwright install chromium
python visuals/tests/check_visuals.py
```

Linux可能需先安裝瀏覽器系統相依套件。脚本檢查18章在1440、768、375、320像素下的頁面溢出、圖數、SVG文字範圍、互動數值、放大、章節切換及單檔离線頁。這不取代原課程後端或正式網站整合測試。
