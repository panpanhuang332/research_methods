# 研究方法18週學程

服務與科技管理研究所一年級，無統計先修，每週120分鐘。依使用者的18週教學圖建立完整18章。貫穿案例為「AI客服回覆更快，顧客滿意度卻未明顯改善」。

## 已實作

- 依使用者附件重建聯合入口：左側古代山水、燭火、古籍；右側現代研究室與城市；中央斜向火光裂縫。手機使用專用直式背景，古代與現代固定左右並立，共同學習紀錄入口位於底部；320×667、390×844、430×932 都可同時看到兩個入口與學習紀錄。
- 18週公開教材、預習、學習目標、案例、圖解、比較表、課堂工作坊、每週成果、教師備課與來源連結。
- 每週4題單選與1題應用問答，共72題單選、18題問答。選擇題60分，問答40分。
- 學生免帳號交卷；交卷後提供選擇題解答解析、問答參考答案與四項規準。
- 問答由授課教師評閱，非AI或關鍵字自動評分；各次練習獨立保存。
- 個人歷史紀錄、章節完成狀態、教師評閱及私人回饋。
- 各章公開討論，填寫顯示名稱即可發言、回覆；作者與教師可移除留言。
- D1保存作答、評分與留言，非瀏覽器儲存；每份作答保存題目與解析快照。
- 40筆明確標示的模擬客服資料；平均數／中位數、樣本數／SE互動示意。

## 手機首頁載入優化

- `<picture>` 以媒體條件挑選手機或桌面構圖，並提供 AVIF/WebP 及不同寬度；手機不載入桌面背景。
- 主圖在 HTML 中即能被瀏覽器發現，使用 `fetchPriority="high"` 與 eager 載入；不再等待 CSS 背景圖。
- 手機 AVIF：480px / 34,266 bytes、768px / 72,111 bytes；WebP 備援約62–126 KB。原背景 PNG 約2.5 MB。
- 桌面 AVIF 約88–115 KB，WebP 備援約153–198 KB。字型 TTF 的顯示引用改為 WOFF。
- 圖片大小是檔案量測，實際開啟時間仍取決於網路與裝置；未宣稱整頁載入時間等比例改善。

## 身分與資料邊界

學生不需帳號或密碼。首次留言或交卷前，伺服器建立隨機瀏覽器身分，使用 HttpOnly、SameSite=Lax Cookie（HTTPS 時 Secure，180 天）。Cookie 不包含姓名或成績；資料保存在 D1。換瀏覽器、使用無痕模式、Cookie 到期或清除網站資料後，無法從該瀏覽器取回原紀錄；教師仍可查看及批改。顯示名稱由學生自行填寫，不代表已驗證的學籍身分，網站亦不收集學號或學生信箱。

教師在 `/teacher` 輸入本站管理密碼。只在 Sites 的 secret 環境變數 `TEACHER_PASSWORD_HASH` 儲存雜湊，格式為 `pbkdf2-sha256:100000:<16-byte salt hex>:<32-byte derived key hex>`。原密碼不可寫入原始碼、HTML、部署封裝或紀錄。教師工作階段為12小時，登出在伺服器撤銷；更新雜湊並部署後，先前教師 Cookie 也會失效。學生名稱、前端角色參數或平台身分標頭都不能取得教師權限。管理密碼僅交付本站擁有者。

所有私人 API 在伺服器檢查 Cookie 身分及所有權；寫入另檢查同源 Origin。答案在 server-only 題庫中，交卷前不傳入客戶端。公開討論只提供顯示名稱，不提供身分代碼或信箱；成績不公開。留言有個人與 IP 頻率限制；教師密碼嘗試每個來源15分鐘最多12次。

遷移只新增瀏覽器工作階段與頻率限制資料表，不刪除既有留言或作答。舊版作答仍供教師管理；由於不再使用原平台帳號，學生的新瀏覽器身分不會自動取得舊帳號作答。

資料庫透過Drizzle schema-only migrations建立。已套用的遷移不可重寫。重複交卷以請求UUID冪等處理；題目必須完整，問答至少10字最多6000字。討論留言最多2000字，有基本頻率限制。

## 內容與教學定位

教材與題目原創編寫，來源為延伸閱讀與查核依據，非外部教材全文轉載。模擬案例與資料不代表真實企業研究。正式研究蒐集前應依所屬機構確認倫理與授權要求。課程以研究判斷為核心；多元迴歸、ANOVA、因素分析與SEM以辨識用途為主。

問答各規準0–10分：0未呈現／核心錯誤，1–4片段，5–7大致正確，8–10正確、具體且有邊界。網站分數是形成性章節紀錄，不直接代替正式學期成績。

## 驗證方式

`node node_modules/typescript/bin/tsc --noEmit` 檢查型別。

`python scripts/verify-course.py` 會使用已建置 Worker，建立獨立的本機測試資料庫與臨時測試密碼，驗證公開頁面、免帳號留言與交卷、答案揭露、重試冪等、跨瀏覽器隔離、教師密碼與評閱、教師標記、留言移除、登出撤銷、到期身分及頻率限制，並驗證舊格式資料經新增遷移後仍可讀取。測試不連線正式站，也不封裝測試資料。

瀏覽器檢查桌面入口與章節、375px容器、行動目錄和統計滑桿。頁面可選的WebMCP章節切換工具以能力偵測啟用；目前檢查瀏覽器不支援document.modelContext，因此未進行WebMCP執行驗證。一般網站操作不依賴此功能。
